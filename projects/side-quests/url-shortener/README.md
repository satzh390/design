# URL Shortener Implementation

This folder contains Java ID-generation examples used by the [URL-shortener design exercise](../../../system-design/exercises/url-shortener/README.md) and its [question prompt](../../../system-design/exercises/questions/11-url-shortener.md). Architecture and diagrams stay in the system-design exercise; implementation examples belong here.

The current code covers Base62 and random ID generation. It is a small standalone example, not a complete URL-shortening service.
