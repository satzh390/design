# 15 — Design a Web Crawler

Design a distributed, polite crawler for search-engine indexing that can process up to one billion HTML pages per month, revisit changed pages, avoid duplicate content, and retain crawled pages for up to five years.

Cover URL frontier and scheduling, fetchers, parsing, deduplication, robots.txt and per-domain politeness, retries, storage, and horizontal scaling. Existing design notes are in the [web-crawler exercise](../web-crawler/README.md).
