# 12 — Design a Search Autocomplete System

Design a search-as-you-type service that returns the top five popular query suggestions for a prefix, with under 100 ms response latency and scale for tens of millions of users.

Cover query collection, aggregation, ranking, prefix lookup, index/trie construction and refresh, storage, availability, and scaling. Existing design notes are in the [type-ahead exercise](../type-ahead-search/README.md).
