# System-Design Exercises

This folder separates question prompts from design materials:

- [`questions/`](./questions/) contains the numbered system-design question briefs.
- Add a question-specific folder here when you have design materials to put in it. Empty placeholder folders are intentionally omitted.
- Implementation code is kept separately under [`projects/side-quests/`](../../projects/side-quests/).
