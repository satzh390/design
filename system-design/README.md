# System Design

System-design material is organized into reusable notes and question-based exercises:

- [`notes/ddia-revision-through-transactions.md`](./notes/ddia-revision-through-transactions.md) — detailed DDIA revision guide covering Chapters 1–7, through Transactions.
- [`notes/design-patterns-cheat-sheet.md`](./notes/design-patterns-cheat-sheet.md) — design-pattern reference.
- [`exercises/questions/`](./exercises/questions/) — one Markdown prompt per system-design question.
- [`exercises/`](./exercises/) — design workspaces created as architecture, diagrams, and notes are added to a question.

Implementation code is separate in [`projects/side-quests/`](../projects/side-quests/). Each implementation README links back to its exercise workspace.
